A [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) bounty entry: one original line (max 200 characters) roasting a gadget used every day — the laptop fan that roars like a jet engine just to open a spreadsheet, then sighs like real work is too much to ask.

`main.ts` validates the line (1–200 characters, single line, not whitespace-only, no leading/trailing whitespace) and writes it to `/output/entry.txt`.

## Run

```sh
node main.ts
```
